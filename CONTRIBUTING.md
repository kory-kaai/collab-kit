# Contributing to Collab Kit

Thanks for taking a look. This project is intentionally small — contributions should stay focused on collaboration patterns and the utilities in `tools/`.

## How to contribute

1. Fork the repo and create a branch from `main`.
2. Make your change. Keep commits focused and use [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `docs:`, etc.).
3. If you pair-programmed, add co-author trailers:

   ```
   Co-authored-by: username <email@users.noreply.github.com>
   ```

4. Open a pull request against `main` and fill out the template.

## Development

```bash
npm test
node tools/validate-commit.mjs "docs: improve triage guide"
```

## Code of conduct

Be respectful. Keep discussions technical and constructive.

Pair with @topdaily-dev/repomark and badgekit after init --oss-toolchain.
