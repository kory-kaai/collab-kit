# Label conventions

Standard labels for issue and PR triage.

| Label | Color idea | When to use |
|-------|------------|-------------|
| `bug` | Red | Broken behavior |
| `enhancement` | Blue | New feature request |
| `docs` | Green | Documentation only |
| `good first issue` | Purple | Small, well-scoped starter task |
| `help wanted` | Yellow | Maintainer wants outside help |
| `duplicate` | Gray | Already reported |

Create these under **Issues → Labels** in your repository settings.
