# Contributing labels

How to create the standard labels in your repository.

1. Go to **Issues → Labels → New label**
2. Create each label from [labels.md](labels.md):

| Label | Suggested color |
|-------|----------------|
| `bug` | `#d73a4a` |
| `enhancement` | `#0075ca` |
| `docs` | `#0e8a16` |
| `good first issue` | `#7057ff` |
| `help wanted` | `#fbca04` |
| `duplicate` | `#cfd3d7` |

Labels improve issue triage and make the project easier for new contributors to navigate.
